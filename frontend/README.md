# Frontend: AI-Driven Scheme Matching

Next.js frontend user interface for marginalized entrepreneurs and administrators.

## Structure
- `src/app`: Application router pages (Profile setup, Scheme search, AI eligibility recommendations, Applications tracker)
- `src/components`: Reusable UI elements (Navbar, Accessibility toggles, Scheme cards, Form inputs)
- `src/lib`: API clients and helper utilities
- `src/styles`: Styling assets and Tailwind configuration

## Local Development
```bash
npm install
npm run dev
```
Runs at [http://localhost:3000](http://localhost:3000).
